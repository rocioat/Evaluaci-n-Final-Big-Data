##**Evaluación Final Big Data**

**Descripción**

Este repositorio contiene el desarrollo de la Evaluación Final Integradora del curso Big Data.

El objetivo del análisis es identificar los factores que influyen en la duración de ejecución de proyectos habitacionales DS27 mediante técnicas de análisis descriptivo y regresión lineal múltiple.

**Fuente de datos**

Dataset utilizado: Proyectos_DS27_agrupados_Codigo_SERVIU.csv

La base de datos corresponde a un conjunto de datos simulado proporcionado por la profesora del curso para fines académicos.
